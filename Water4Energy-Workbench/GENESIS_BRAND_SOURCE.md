# Genesis Mission logo source

Retrieved November 6, 2026, from official U.S. Department of Energy sources. Artwork is stored unmodified; no crop, recoloring, tracing or logo reconstruction was performed.

## Preferred mark for a white header

- Local asset: `public/assets/brand/genesis-mission-black.png`
- Original URL: https://www.energy.gov/sites/default/files/2026-03/Genesis_Logomark%20-%20Black.png
- Official page: https://www.energy.gov/undersecretaryforscience/genesis-mission/genesis-mission
- On that page the image alt text is **new black and white genesis logo**, and the displayed image URL is `/sites/default/files/styles/full_article_width/public/2026-03/Genesis_Logomark%20-%20Black.png?itok=XcWnzu9Q`. The downloaded file is the original source underlying that Drupal display style.
- The image is a black circular/radiating Genesis logomark on transparency, with substantial built-in clearspace. It is not a horizontal wordmark. Show it proportionally and place any ordinary interface label “Genesis Mission” outside the artwork.

## Optional original reverse icon

- Local asset: `public/assets/brand/genesis-mission-white-on-black.png`
- Original URL: https://www.energy.gov/sites/default/files/2025-11/Genesis_icon_s.png
- The current official Mission page references it in `link rel="image_src"` and its Open Graph image metadata. It is a white mark on an opaque black background, not a full-color palette.

## Colors

The preferred current Mission artwork is monochrome, using black `#000000` and transparency. The optional icon uses white `#FFFFFF` and black `#000000`. No formal Genesis Mission color specification or prescribed navy/red hex palette was located in the bounded official-source review. A deep-navy application background is a complementary UI design decision, not an asserted official Genesis color. Existing VISTA AmSC lockups are a different combined subbrand and are not used as substitutes for the generic Mission mark.
