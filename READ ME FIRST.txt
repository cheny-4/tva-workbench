Water4Energy workbench — combined Mac package 1
Interface v0.15.1

Share this single ZIP. There is no second setup download.

1. Extract the complete ZIP into a writable folder on the Mac.
2. Double-click Start TVA Workbench.command inside TVA-Workbench.
3. Keep Terminal and VISTA open. Use the local address printed by this copy.

Live chat requires VISTA installed and your own model/provider credentials in
VISTA Settings. VISTA normally supplies Python; otherwise Python 3.9+ is needed.
No GitHub login, npm or pip commands are required. VISTA itself is a separate
application and is not redistributed in this ZIP.

The launcher opens installed VISTA if needed, loads eight saved-evidence skills,
indexes nine documents and verifies 32 original April evidence files. Later
questions can create additional source-checked displays. Indexing may take a few
minutes. Matching installations are reused without duplicates. Known v0.13.1,
v0.13.2 and v0.14.0 backend items can be verified, backed up and upgraded;
interface v0.14.1 used that same v0.14.0 backend. Unknown local edits, shared
skills and differing results are preserved and reported.

If port 8765 is occupied, this copy uses another local port. Reopen the printed
address instead of an older saved tab. Ctrl+C stops the workbench; VISTA remains
under its application's control. If setup needs attention, Terminal explains it
and the webpage can still open for design review. Correct the issue and rerun
the same launcher.

For a nonstandard installation, set W4E_VISTA_INSTALL to the VISTA package
directory and/or use:
python3 launch_workbench.py --backend-url http://127.0.0.1:8001

Start on HEADWATER development. Chat remains on the left; explanations and
figures appear on the right. Choose a question, review its editable request,
then press Send. Hypothesis lab shows the completed 24 October 2026 research
cycle. TVA selects the separate 16–22 April 2019 case. Each context remembers
its own conversation and draft. The message-box height is adjustable.

The five supplied figures retain distinct scopes: four-week weather comparisons
and whole-month April refinement at about 4 km. Monthly rainfall statistics in
mm/day are separate from weekly rainfall totals and the frozen Trial 0 case.
The existing six April questions, original HEADWATER answers and 32 original
April evidence files are retained. Source links explain what each figure shows.

Included: interface and ORNL/Genesis marks; one Mac launcher; project setup;
eight adapters with pinned sources; nine indexed guides/sources; original saved
evidence; five supplied figures; integrity manifest.
Excluded: credentials, VISTA databases/settings, chats, local UUIDs, raw ERA5
arrays, checkpoints and cluster access. Paper PDFs are not bundled.

Setup sends no agent prompt and starts no training, scientific inference,
scoring, download or HPC job. A saved board state is not execution permission.
The optional dam skill still needs an agreed reservoir/rule. The exact original
Trial 0 scorer remains missing. Review live answers with their cited evidence;
free-form model behavior and a first launch on another laptop are not
certified by local tests. Unreadable responses offer a draft-only manual retry.

Troubleshooting
- If macOS blocks the command, use Finder's Open action and the approval flow
  allowed by your institution. Terminal equivalent:
  sh "Start TVA Workbench.command"
- If source indexing is pending, keep VISTA open and rerun when it finishes.
- If an existing item differs, review the preserved conflict in VISTA.
- .local/setup-receipt.json holds non-secret readiness counts; verified upgrades
  retain complete originals in .local/upgrade-backups. Do not forward .local.
